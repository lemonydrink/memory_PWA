# メモリ・安全性検証（2026-11-07）

リポジトリのソース確認と、隔離したChromeブラウザでのテストを実施しました。実アカウント・本番の教材は変更していません。

## 発見と修正

| 箇所 | 問題 | 修正 |
| --- | --- | --- |
| 同期の選択ボタン | 画面を隠すだけでは、クリック処理が端末・クラウドのバックアップのコピーを保持し続ける | 完了・キャンセル・画面移動・教材変更・オフライン移行時にボタンとハンドラを除去 |
| 教材を閉じる処理 | 非表示の学習・問題・解答DOMと、直前の問題リストが残る | 進行位置を記録してから描画要素と参照を解放。画像のObject URLも従来どおり破棄 |
| Mermaidの描画待ち | 描画が並んだ際、各処理が一時測定用DOMを作成してから待機する | 一時DOM作成前に直列化。閉じられた教材の待機処理は描画を省略 |
| オフライン準備 | MessageChannelのポートとService Workerの状態変更リスナを明示的に解放していない | 完了・失敗・タイムアウト時にポートを閉じ、完了した状態監視を解除 |
| 起動途中の通信失敗 | 再試行で初期化済みのスクリプトを再実行し得る | 読み込みを一本化し、正常に読み込めたスクリプト以降から再試行 |
| ログアウトと認証確認の競合 | 進行中の認証確認がログアウト後に画面を開き得る | 先にログアウト予定を記録して再開を防ぎ、確認処理を待ってオフライン許可を消去 |

非表示DOMの保持は、確認した範囲では直前の教材に限定されます。「操作回数に比例する無制限なリーク」とは区別しています。同期で保持されるコピーは画像を含むため、不要な保持をなくす効果があります。

## 実測とテスト結果

メモリテストでは、画像・数式付き学習ノート → テスト → 解答 → 一覧の一連の操作を140回繰り返しました。最初の20回をウォームアップとして、その後120回の前後でGCを実行しました。

- GC後のJavaScriptヒープ：10,545,742 → 9,819,636バイト（差分 -726,106バイト）。今回の測定では増加していません。
- 最終的に残ったテスト対象の画像Object URL：0件。
- 閉じた教材の対象描画DOM：0要素。問題リストへの参照も解除。
- Mermaid教材を25回開閉した後、一時測定DOM・一時描画SVGの残留なし。
- 起動途中に読み込みエラーを注入しても、再試行後のapp.js読み込みとアカウント表示は各1個。
- オフライン準備用MessagePortの未解放：0件。
- 認証確認の応答を遅延させて途中でログアウトしても、画面のロックを保持し、オフライン許可を消去。
- MarkdownへのHTMLタグ混入・TeXへのjavascriptリンク混入で、実行可能なHTMLが生成されないことを確認。

既存のブラウザ回帰テストも実施しました。赤シート・スワイプ・表・TeX・Mermaid・ノート削除・同期キャンセル・画像の同期復元・ネットワーク遮断後の起動が対象です。同期の完了・キャンセル・復元後に選択ボタンのハンドラが残らないことも検証しています。

認証APIのテストでは、匿名アクセス拒否、許可リスト、OAuth state・nonce・PKCE、コールバック再利用の拒否、Googleトークンのaudience・有効期限・メール確認、90日Cookieの属性、セッションのハッシュ保存、アカウント失効、CSRF対策、クラウドのアカウント分離、古い世代による上書き拒否、ログアウトによる失効を確認しました。Google・D1・R2はフィクスチャを使い、署名検証にはブラウザのWebCryptoを使用しています。

## 再実行

Python 3、cryptography、Chrome/Chromiumが必要です。parserテストにはgjsを使います。

```sh
gjs tests/parser.js
python3 tests/run_browser.py auth
python3 tests/run_browser.py app
python3 tests/run_browser.py memory
```

memoryモードのGC公開・精密メモリ測定フラグ、通信失敗注入、ポート追跡はテスト専用のChromeプロファイル内だけで使用します。本番には追加しません。

## 検証の限界

この結果は、今回のChrome・テストデータ・反復回数に対する結果です。全環境でメモリリークが存在しないことを保証するものではありません。JavaScriptヒープの値には、ブラウザ全体のメモリ、画像デコード用領域、GPU領域、ディスクキャッシュは含まれません。IndexedDBの教材やオフラインキャッシュは、利用のために意図的に保持しています。

iPhone/iPadのSafari実機、数日間の連続利用、大量画像・最大50MiBバックアップのピークメモリと、本番Cloudflare環境での負荷は今回未測定です。大容量のJSON・Base64変換と画像デコードでは、一時的にファイルサイズを超えるメモリを使う可能性があります。同梱ライブラリの全既知脆弱性を調査した監査ではありません。

ローカル教材は暗号化していません。端末やブラウザの保存領域を操作できる人から教材を保護する仕組みではありません。オフライン認証も端末上の検証に依存するため、端末所有者によるデータやプログラムの改変を防ぐ境界にはできません。許可リストから削除しても、通信がない端末には最大3日の許可期限までは失効を即時通知できません。
