# 赤シート暗記アプリ PWA仕様書 v1.0.0

確定日 2026年11月6日

## 1. 目的と管理単位

教材を読み込み、本文の指定箇所を赤シートで隠して覚えるか、一問一答で思い出す。製品版はPWA（インストール可能なWebアプリ）として提供する。iPhone 16eの縦向き（390 × 844 pt）を画面設計の基準とし、Safariの表示領域や端末のセーフエリアに合わせて調整する。

| 単位 | 内容 |
| --- | --- |
| フォルダ | ノートと子フォルダをまとめる。赤シートノートとテストノートを同じ場所に置ける。 |
| 赤シートノート | 見出し、本文、隠す文字列、必要に応じて画像を含む。開くと赤シート画面に進む。 |
| テストノート | 順序を持つ一問一答を含む。各問は質問と答えを持ち、補足、解説、画像を添えられる。開くとテスト画面に進む。 |
| 教材ファイル | 読み込み・書き出しに使うファイル。読み込み時に内容に応じて1件または2件のノートを作る。 |

たとえば「生物基礎 › 細胞のしくみ」フォルダに「細胞の構造と働き（赤シート）」と「細胞の確認問題（テスト）」を並べられる。

## 2. 配信・オフライン・端末内保存

| 項目 | 要件 |
| --- | --- |
| 配信 | Cloudflare PagesからHTML・CSS・JavaScript・アイコンなどを固定のHTTPS URLで静的配信する。通常の学習と教材ファイルの読み込み・書き出しは端末上で処理する。 |
| 起動 | iPhoneのSafariでURLを開き、許可されたGoogleアカウントでログインする。ホーム画面から使う場合は、共有メニューの「ホーム画面に追加」でWebアプリとして追加する。Web App Manifestに名前、アイコン、起動URL、表示モードを設定する。ホーム画面からの初回利用時もログインを確認する。[Appleの手順](https://support.apple.com/ja-jp/guide/iphone/iphea86e5236/ios) |
| オフライン | ログイン後にService Workerで画面ファイルを保存する。有効なオフライン利用許可がある間は、再起動、ノート一覧、赤シートとテスト、端末上のファイルの読み込み・書き出しとファイルによるバックアップ・復元を利用できる。クラウドへの保存とクラウドからの復元はオンラインで行う。 |
| 教材の保存 | ノート、画像、フォルダ構造をIndexedDBにアカウント別で保存する。同じアカウントと利用環境で開き直したときに、保存済みの教材と整理結果を復元する。書き込みが失敗した場合は、利用者に保存結果を知らせる。 |
| 教材の持ち運び | ノート単位では教材ファイルを使い、フォルダ構造ごと持ち運ぶ場合は第7節のバックアップを使う。WebKitではホーム画面のWebアプリとSafariのWebサイトデータが分かれるため、移動先で読み込みまたは復元を行う。[WebKitの保存領域の説明](https://webkit.org/tracking-prevention/) |
| 更新 | 配信ファイルのキャッシュを版ごとに切り替える。アプリの更新後も保存済みのノート、画像、フォルダ構造を引き継ぐ。 |

### サイト全体のアクセス管理

| 項目 | 要件 |
| --- | --- |
| 認証と利用許可 | Cloudflare Accessでサイト全体を保護する。認証方法はGoogleログインに統一し、管理者が個別に登録したメールアドレスだけにアクセスを許可する。学習画面、ノート一覧、静的ファイル、バックアップAPIを保護対象にする。[Googleとの連携](https://developers.cloudflare.com/cloudflare-one/integrations/identity-providers/google/)・[Accessポリシー](https://developers.cloudflare.com/cloudflare-one/access-controls/policies/) |
| 配信先の保護 | 本番のPages URL、利用する独自ドメイン、プレビューURLにAccessを適用する。プレビューは開発・確認担当者だけに許可する。公開前に、Pagesの既定URLやプレビューへの直接アクセスでも同じ保護が効くことを確認する。[Pagesの本番URLとプレビューの保護](https://developers.cloudflare.com/pages/platform/known-issues/#enable-access-on-your-pagesdev-domain) |
| 権限の管理 | 利用者の追加・削除は管理者がCloudflare側で行う。許可を取り消すときは許可リストから削除し、既存のAccessセッションも失効させる。管理者アカウントには多要素認証を設定する。[Accessのセッション管理](https://developers.cloudflare.com/cloudflare-one/access-controls/access-settings/session-management/) |
| 起動時の確認 | オンラインで起動・再開するときは、学習画面を出す前にネットワーク経由で認証と利用許可を再確認する。ログインが必要な場合は再認証へ案内し、利用が許可されていない場合はアクセス拒否を表示する。オフライン利用への切り替えは通信できない場合に限る。 |
| オフライン利用許可 | オンラインで認証と利用許可を確認したときに、サーバー署名付きの利用許可をその端末に発行する。期限は確認から最長24時間かつ認証セッションの期限内。通信できないときは、署名と期限が有効な場合に限り、そのアカウントの端末内教材を開ける。期限切れの場合はオンラインでの再認証を案内する。 |
| ログアウトと失効 | ログアウトまたは権限失効を確認したときは、学習画面を閉じ、端末のオフライン利用許可と表示中のアカウント状態を消去する。通信が途切れている端末への権限変更は、再接続時または利用許可の期限到来時に反映する。端末に保存済みの教材や書き出し済みのファイルは、端末のロックとOSの保護に従う。 |
| 操作記録 | 管理者がAccessのログイン結果とバックアップ操作の日時・結果を確認できるようにする。バックアップの操作記録は利用者ID、操作名、日時、結果に絞る。 |

## 3. メニューとノート一覧

- 起動時の入口はノート一覧。上部のパンくずで現在のフォルダを確認し、上位フォルダに戻れる。「すべて」が最上位。
- 左端から右へスワイプするか、左上のボタンをタップすると、左からメニューが開く。項目は「ノート一覧」と「ファイルを読み込む」の2つ。メニュー内を左にスワイプするか、×または背景をタップして閉じる。
- 一覧でフォルダをタップすると中身を表示する。ノートには「赤シート」または「テスト」を表示し、タップするとその種類に対応した画面が開く。
- 「フォルダを作る」で現在の場所に子フォルダを作成する。ノートの「…」から名前と保存先を変更する。移動先には最上位や別のフォルダを選べる。
- ノート、画像、フォルダ構造は端末内に保存する。読書位置、シートの位置、テストの進行状態はノートごとにセッション中保持し、一覧を経由して開き直したときに復元する。

## 4. 赤シート画面

| 項目 | 動作 |
| --- | --- |
| 本文 | タイトル、見出し、段落、画像を教材の順に表示する。本文の `**太字**` を赤字にする。1段落に複数の暗記対象を指定できる。 |
| シート | 画面下部に固定する。つまみの上下ドラッグに追従し、指を離すと上げた位置か下げた位置に収まる。タップでも切り替えられる。最初に開いたときは下げた位置。 |
| 隠し方 | シートと重なった部分の赤字だけを隠す。通常の本文はシートの下でも読める。赤字がシートの外に出ると再表示する。 |
| スクロール | シートの外側を縦にスワイプすると本文が動き、ヘッダーとシートは画面内の同じ位置に留まる。最後の段落もシートの外に送って読める。 |
| 画像 | 画像は本文と一緒にスクロールし、図中の文字も含めて一枚の素材として表示する。シートと重なっても画像の見た目を保つ。隠す対象は本文の太字に限る。 |

## 5. テスト画面

教材に書かれた順に1問ずつ出題する。質問と答えは、赤シートノートの太字指定とは独立して教材に記述する。

| 状態 | 画面と操作 |
| --- | --- |
| 出題 | 上部にノート名と問題番号、中央に問題を表示する。質問側に補足や画像があれば、この段階で表示する。 |
| 答えの確認 | 画面下部の上向き矢印がある領域を上にスワイプするか、タップする。問題の下に答えを表示し、解説があれば同時に表示する。答え側・解説側の画像もここで表示する。 |
| 問題送り | 答えを確認すると「次の問題」が表示される。押すと次の問題を出題状態から表示する。 |
| 終了と再開 | 最後の答えの確認後に「テストを終える」で完了画面へ進む。「もう一度」で最初の問題に戻る。 |

## 6. 教材の読み込みと書き出し

### 読み込み

「ファイルを読み込む」または一覧の「＋ 読み込む」から、iPhoneのファイル選択画面を開く。選んだ教材ファイルをブラウザ内で読み取り、その時点で一覧に表示しているフォルダに追加する。

| ファイル内の構成 | 作られるノート |
| --- | --- |
| `## 学習` のみ | `#` 見出しを名前とする赤シートノート1件。 |
| `## テスト` のみ | `#` 見出しを名前とするテストノート1件。 |
| 両方 | 赤シートノートとテストノートを同じフォルダに1件ずつ追加する。テストノートの初期名は「ノート名の確認問題」。 |

同じ教材を再度読み込むと、新しいノートとして追加する。教材全体の構造と参照画像を検証してから登録する。問題や画像が欠けている場合は修正箇所が分かるエラーを表示し、そのファイルの登録を中止する。

### 書き出し

PWAの書き出し単位は、選択したノート1件。現在のノート名を `#` 見出しに使い、種類に応じて `## 学習` または `## テスト` を収録する。本文、隠す箇所、質問と答え・解説の対応、表示順、参照画像を再読み込みできるように保存する。生成したファイルはiPhoneの「ファイル」に保存できるようにする。読書位置などはセッション中の表示状態として扱う。書き出し操作の配置はPWA実装時に決める。

### ファイルの種類

| 形式 | 内容 |
| --- | --- |
| `<ノート名>.redsheet.md` | 画像のない教材。UTF-8のMarkdown。 |
| `<ノート名>.redsheet.zip` | 画像付き教材。ZIPの直下に `note.redsheet.md` を置き、PNGまたはJPEGを `assets/` 配下に入れる。 |

画像は `![図の説明](assets/cell.png)` のように、教材内の相対パスで参照する。アプリは同梱画像を使うので、教材はオフラインでも読める。

### Markdownの規則

| 記法 | 意味 |
| --- | --- |
| `# ノート名` | ファイル先頭のタイトル。 |
| `## 学習` と `## テスト` | 種類を示す見出し。少なくとも一方を使い、使う見出しは各1回。 |
| 学習内の `### 小見出し` と `**太字**` | 小見出しと段落で本文を組み立てる。太字を赤シートの対象とする。 |
| テスト内の `### 質問文` | 1問の開始。通常は見出しの直後から答えを書く。 |
| テスト内の `#### 問題` と `#### 答え` | 質問側に補足や図を添える場合に、同じ問の中でこの順に使う。 |
| テスト内の `#### 解説` | 任意。答えの後に置き、次の問題またはセクション末尾までを解説として扱う。 |

学習には本文を、テストには質問と答えの組を1件以上記載する。答えは、`#### 解説`、次の質問、またはテストセクションの末尾で終わる。

### 記述例

次は、読み込むと同じフォルダに2件のノートを作る画像付き教材の例。ZIP内の `assets/cell.png` には、矢印で核を示す図を入れる。

```markdown
# 細胞のしくみ

## 学習

### 細胞と遺伝情報

生物のからだをつくる基本単位は**細胞**です。
真核細胞では、**核**に**DNA**の大部分が収められています。

![矢印で細胞内の構造を示した図](assets/cell.png)

## テスト

### 図の矢印が示す構造は何？

#### 問題

![矢印で細胞内の構造を示した図](assets/cell.png)

#### 答え

核

#### 解説

核には、細胞のDNAの大部分が収められています。

### 生物のからだをつくる基本単位は何？

細胞
```

## 7. バックアップと復元

ノート一覧に「バックアップ」への入口を設ける。保存対象は全ノート、参照画像、フォルダ階層と並び順。読書位置、シートの位置、出題の進行状況はセッション中の状態として扱う。

| 機能 | 要件 |
| --- | --- |
| ファイルに保存 | 全体を1つの `.redsheet-backup.zip` にまとめ、iPhoneの「ファイル」に保存する。選んだバックアップファイルから全体を復元できる。 |
| クラウドに保存 | サイトにログイン中のアカウントで「クラウドに保存」を選ぶと、そのアカウントの端末内ライブラリ全体を保存する。初版はアカウントごとに最新の成功分1件を保持し、画面に保存日時とノート件数を表示する。 |
| クラウドから復元 | 別端末やホーム画面のWebアプリで同じGoogleアカウントにログインし、保存済みのバックアップを選んで復元する。 |
| 復元の確認 | バックアップの日時とノート件数、現在のライブラリ全体を置き換えることを表示し、利用者が確認してから反映する。現在のライブラリをファイルに保存できる導線を用意する。 |
| 失敗時 | 保存が失敗した場合は、前回成功したクラウドバックアップを保持する。復元前に形式と参照ファイルを検証し、検証・書き込みの失敗時は端末のライブラリを保持する。 |
| クラウドから削除 | 本人が確認したうえで保存済みのクラウドバックアップを削除できる。削除の対象はクラウドのコピー。 |

### バックアップファイルの構成

ZIPの直下に `backup.json` を置く。メタデータには形式識別子 `redsheet-backup`、形式バージョン `1`、保存日時、フォルダとノートの一覧を入れる。フォルダ一覧はID・名前・親IDを持ち、ノート一覧はID・所属フォルダID・教材ファイルのパスを持つ。最上位は親IDまたは所属フォルダIDを `null` で表す。各ノートは `notes/` 配下に第6節の教材形式で格納し、復元時はメタデータの一覧順を使う。

### Cloudflareの構成と料金管理

- 静的ファイルはCloudflare Pages、認証はCloudflare Access、利用許可の発行とクラウドバックアップAPIはPages Functions、バックアップ本体は非公開のR2 Standardバケットで扱う。Service Workerのキャッシュは画面ファイルに限定する。署名付きのオフライン利用許可は、キャッシュと分けてアプリの保存領域に記録する。[Pages FunctionsのR2連携](https://developers.cloudflare.com/pages/functions/bindings/)
- APIの各リクエストでAccessトークンの署名、発行元、対象アプリ、有効期限を検証する。検証済みの利用者IDから保存先を決定し、その本人のバックアップに限って保存・取得・削除を許可する。保存・削除は正規のサイトを起点とするリクエストに限定する。[Accessのトークン検証](https://developers.cloudflare.com/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/validating-json/)
- 初版のクラウド保存は明示操作で行い、1アカウントにつき50 MiB・1件を上限とする。管理側でクラウド保存機能を停止した場合も、利用を許可されたアカウントは学習とファイルによるバックアップを利用できる。
- 2026年11月6日時点で、Functionsを経由しない静的配信リクエストは無料。Pages FunctionsはWorkersの利用枠を消費する。R2は利用登録が必要で、Standardの無料枠は月10 GB-month、Class A 100万件、Class B 1,000万件。無料枠を超えたR2の利用は従量課金のため、公開前に最新の条件を確認する。[Pagesの料金](https://developers.cloudflare.com/pages/functions/pricing/)・[R2の利用登録](https://developers.cloudflare.com/r2/get-started/)・[R2の料金](https://developers.cloudflare.com/r2/pricing/)
- 同日時点で、Cloudflare Zero Trustの無料プランは最大50ユーザー。運用開始時は無料枠内の人数で提供し、利用者数とCloudflareの使用量を確認する。[Cloudflare Zero Trustのプラン](https://www.cloudflare.com/plans/zero-trust-services/)

## 8. HTMLデモとの対応

[ブラウザ操作デモ](anki-preview.html) は、ノート一覧、フォルダ作成、ノートの名前変更・移動、ファイル読み込み、赤シートとテストの操作を確認するための単体HTML。最初はサンプルフォルダ「生物基礎 › 細胞のしくみ」を表示する。Cloudflareへの配信、認証とアクセス管理、ホーム画面起動、オフライン用のキャッシュ、書き出し、バックアップ・復元は製品版の実装範囲とする。

| 項目 | HTMLデモでの扱い |
| --- | --- |
| ファイル選択 | `.md` と `.zip` を受け付ける。デモの上限はファイル1件24 MiB。ZIP内の教材と対応画像の展開後合計にも同じ上限を適用する。 |
| 保存 | ブラウザ内の保存領域を使う。保存できない環境ではメッセージを表示し、そのセッション中はノートを操作できる。 |
| 書き出し | 第6節にPWAの要件を定義する。デモで試せるファイル操作は読み込み。 |
| 実機確認 | iPhoneのSafariとホーム画面のWebアプリで、ファイル選択、ジェスチャー、描画を確認する。 |

## 9. 受け入れ確認

1. 一覧で赤シートノートとテストノートを区別できる。フォルダを作り、ノート名を変更して別フォルダへ移し、起動し直しても整理結果が残る。
2. 学習のみ・テストのみ・両方の教材から、それぞれ1件・1件・2件が選択中のフォルダに追加される。画像参照が欠けたZIPはエラーになり、既存の一覧は保持される。
3. 赤シートを上下に動かし、重なった赤字だけが隠れる。図中の文字と通常の本文は読める。スクロールで最後の段落まで確認でき、一覧経由で戻ると同じ位置から読める。
4. テストで上スワイプまたはタップをすると答えと解説が現れる。質問側・答え側の画像がそれぞれの段階で表示され、次の問題、終了、再開まで進める。
5. PWAでノート1件を書き出して「ファイル」に保存し、再度読み込む。種類、タイトル、教材の順序、暗記対象、質問・答え・解説、参照画像が保持されることを確認する。
6. iPhoneのSafariでHTTPSの配信先を開き、許可されたアカウントでログインしてホーム画面に追加する。ホーム画面のWebアプリで利用許可を取得し、その有効期間内に機内モードで開き直して、保存済みの画像付き教材と両モードを使えることを確認する。
7. オフラインのまま端末内の教材を読み込み、書き出したファイルを保存できることを確認する。再接続してアプリを更新し、ノート、画像、フォルダ構造を引き継げることを確認する。
8. 画像付きノートを含むライブラリをバックアップファイルに保存し、オフラインで復元する。ノート、画像、フォルダ階層と並び順が一致することを確認する。
9. クラウドへ保存し、同じアカウントで別端末から復元する。保存失敗時は前回のコピー、復元失敗時は端末のデータが保持されることを確認する。クラウドへのアクセスが保存した本人のみに限られ、上限超過時はエラーが表示されることを確認する。
